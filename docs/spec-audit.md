## Things found outside my files (not changed)

- Demo data hygiene: repeated verification runs (several engineers, this round and the last) left PL-1 at V11 and AFFILIATE-DISCLOSE at V5 with "Verification run…" reasons in their histories, and ~60 `[test] stress …` sample ads in ClearPath. Before the demo: `scripts/cleanup-workspace.ts` for the ads; the rule and product histories are immutable by design, so either accept them or re-seed a fresh workspace for the demo.
- New ad rate limit ("You have added 60 ads in the last hour") is per user and shared by every test suite signed in as the reviewer account; sequence bulk tests, or give them their own member.

- `lib/data/rules-labels.ts`: `policy: "Company policy"` → "Company rule" (done by the integrator), so the word is gone from the UI entirely.
- Dev-only: while two Playwright clients were connected to the same `next dev`, the HMR channel ping-ponged (`building` → chunk `restart` → reload, ~9 reloads/s) until one client left. Nothing in the product; worth knowing for anyone running two browser suites against one dev server.
- Database message for accepting an expired invitation (`accept_invitation`, PT409: "ask an owner to resend it") still says "resend"; it only shows if the link expires between rendering and clicking Accept, and it now passes through the profile→workspace translation.
